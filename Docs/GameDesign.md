# DeckSaga —— 卡牌机制体系 & 四角色构筑设计（卡牌战斗向）

> 机制 = **玩家增益/敌人减益（数字管线）+ 牌库/手牌操作 + 战斗修饰**，这是卡牌游戏的核心。
> 每个角色有**专属机制侧重**，卡池 ≥ 30，**含通用卡（不强绑流派）**。
> 卡无属性/元素，靠**状态效果 + 牌库构筑**做差异化。先给机制，再给卡池。

---


## 0. 卡牌类型（Card Type）

每张卡属于一种类型，**部分机制/卡会按类型生效**（如「本回合攻击牌+3」「抽一张技能牌」）：

| 类型 | 说明 |
|------|------|
| **攻击牌 ATTACK** | 造成伤害为主的牌 |
| **技能牌 SKILL** | 格挡/增益/抽牌/牌库操作等非伤害牌 |
| **能力牌 POWER** | 打出后**本场持续生效**的光环/常驻效果（升级版增益） |
| **状态牌 STATUS** | 临时附带的负面牌（如 Wound），用完即走 |
| **诅咒牌 CURSE** | 被塞进卡组的负面牌（扣费/扣血），无正效果 |

> 示例：`力量/荆棘/护体` 可做成**技能牌**（单次）或**能力牌**（本场光环）。
> 每个角色的「境界/觉醒」类卡 = **能力牌**，是构筑的方向锚。

# 第一部分 · 机制体系

## 1.1 增益（玩家 buﬀs）
| 机制 | 说明 |
|------|------|
| **力量 STRENGTH** | 每层使攻击伤害 +1 |
| **敏捷 DEXTERITY** | 每层使「获得格挡」+1 |
| **荆棘 THORNS** | 受击时反击攻击者 X 點 |
| **吸血 LIFESTEAL** | 造成伤害按 % 回血 |
| **怒气 FURY** | 本回合每打出一张攻击牌，该攻击 +X |
| **护体 WARD** | 格挡不随回合结束清零（持续格挡） |

## 1.2 减益（敌人 debuffs）
| 机制 | 说明 |
|------|------|
| **易伤 VULNERABLE** | 受到伤害 +50% |
| **虚弱 WEAK** | 攻击伤害 -25% |
| **燃烧 BURN** | 回合末 X 伤，层数 -1 |
| **中毒 POISON** | 回合末 X 伤，层数不减（持续掉） |
| **眩晕/定格 STUN** | 跳过下回合行动 |
| **嘲讽 TAUNT** | 强制敌人攻击该目标（控场） |
| **破甲 ARMOR_BREAK** | 无视目标格挡/削格挡 |
| **枯竭 DEPLETE** | 目标攻击力 -1/层（叠加） |

## 1.3 牌库/手牌操作
| 机制 | 说明 |
|------|------|
| **抽牌 DRAW** | 从捕牌堆抽 |
| **弃牌 DISCARD** | 弃一张牌换效果 |
| **删除 REMOVE** | **永久从卡组移除一张牌**（剔牌） |
| **消耗 EXHAUST** | 用后本场消失（一次性） |
| **保留 RETAIN** | 回合结束该牌留手 |
| **升级 UPGRADE** | 卡被增删后永久强化词条 |
| **复制 COPY** | 复制一张牌加入手牌 |
| **回手 RETURN** | 收回已用牌到手上 |
| **感知 SCRY** | 看牌堆顶 N 张并重排 |
| **洗混 SHUFFLE** | 弃牌堆洗回牌堆 |

## 1.4 战斗修饰
| 机制 | 说明 |
|------|------|
| **多段 HIT×n** | 一次打出 n 次伤害 |
| **穿透 PIERCE** | 无视格挡 |
| **处决 EXECUTE** | 目标生命低于阈值直接斩杀 |
| **换血 SACRIFICE** | 代价：失去生命 |
| **能量 ENERGY** | 获得额外魔力 |

# 第四部分 · 落地原则

1. **状态效果**加进 `StatusEffectType`：力量/敏捷/荆棘/吸血/怒气/护体 / 易伤/虚弱/燃烧/中毒/眩晕/嘲讽/破甲/枯竭。
2. **`Card` 加 `CardType`（攻击/技能/能力/状态/诅咒）** + 专属字段（exhaust/retain/removal/upgrade/copy/power 标记），`CardSystem` 处理。
3. **战斗修饰**：`HIT×n`、`pierce`、`execute`、`sacrifice` 作为 `DealDamageEffect` 的字段。
4. **能力牌(POWER)**：打出后向英雄挂「本场光环」（如 `持久战意`/`狂血沸腾`/`血之契约`/`灼热流转`），在回合开始或结算时触发。
5. **每角色卡池 ≥30** 逐张建 `CardData`；**公共卡池**（打击/防御/重击/铁壁/战吼/急救）所有角色通用。

> 这版是**卡牌战斗机制向**的设计。你确认机制清单，我们选一个角色先落地数值 + 建卡。

# DeckSaga —— 深度规则 & 四角色构筑设计

> 目标：**机制可扩展**、每个角色**独立卡池 ≥ 30 卡种**、基于**多流派(archetype)**构筑、
> 卡牌**不强绑流派、留足通用性**（通用卡兼容多构筑）。
> 机制灵感对标 Slay the Spire / Monster Train / Griftlands 的成熟设计，落地时逐条实现。

---

## 0. 全局数值基调

- 生命上限：70~80。魔力上限：3（回合开始时回满）。
- 起手 5 张、每回合抽 5 张、弃掉手牌再抽（回合结算）。
- 敌人：3 个，各有攻击力/生命，回合末依次行动。
- **构筑来源**：角色专属卡池 + 公共卡池；卡牌按 **普通/稀有** 掉落，稀有定义流派。

---

## 1. 核心机制体系（基础词汇表）

### 1.1 战斗数值 & 状态
| 机制 | 说明 | 来源灵感 |
|------|------|---------|
| **力量 STRENGTH** | 每层使攻击伤害 +1 | StS 力量 |
| **敏捷 DEXTERITY** | 每层使出牌获得格挡 +1 | StS 敏捷 |
| **虚弱 WEAK** | 目标攻击伤害 -25%（层数=回合） | StS 虚弱 |
| **易伤 VULNERABLE** | 目标受到伤害 +50% | StS 易伤 |
| **燃烧 BURN** | 回合末造成层数伤害，层数-1 | 现有一半 |
| **中毒 POISON** | 回合末造成层数伤害，层数-1（回合结算） | 独立 DoT |
| **格挡 ARMOR** | 本回合抵伤，回合结束清零 | 现有 |
| **荆棘 THORNS** | 受击时反击攻击者 | 现有增强 |
| **吸血 LIFESTEAL** | 造成伤害按比例回血 | 血魔核心 |
| **击退/位移** | 受击后退 | 已做 |

### 1.2 出牌规则扩展
| 关键词 | 说明 |
|--------|------|
| **消耗 EXHAUST** | 打出的牌进入弃牌堆，本场对局不再出现（一次性强力牌） |
| **保留 RETAIN** | 打出的牌不变、回合结束留手 |
| **X 费** | 消耗当前全部剩余魔力，按花费结算 |
| **多段 HIT×n** | 一次打出 n 次伤害/效果 |
| **回响 ECHO** | 该牌打出后再免费自动打一次 |
| **复制 COPY** | 本回合下一张牌复制一次 |
| **换血 SACRIFICE** | 代价：失去生命换取强效果 |
| **升级 UPGRADE** | 卡纳入卡组后可升级成更强版 |

## 4. 落地优先级（建议顺序）

1. **补 4 个状态机制**：`STRENGTH`、`DEXTERITY`、`WEAK`、`VULNERABLE`、`POISON`、`THORNS`、`LIFESTEAL`。
   - 在 `StatusEffectType` 加枚举 + `StatusEffectsUI` 图标 + `DamageSystem`/回合结算统一处理。
2. **出牌关键词**：`消耗 EXHAUST`、`保留`、`X费`、`多段`、`回响`、`复制`、`升级`。
   - 在 `Card`/`Effect` 加规格字段，`CardSystem`/`PlayCardPerformer` 按关键词运行。
3. **通用卡池**建 `CardData` 资产（公共池 12 张 × 现有/新机制）。
4. **每角色卡池 30+**：逐张建 `CardData`，放进 `HeroData` 的「起始卡组 + 卡池」。
5. **角色切换 + 遗物**：`HeroData.Image` + `HeroView` Animator controller 切到对应角色；`MatchSetupSystem` 挂初始遗物逻辑。

> 本稿为**设计蓝图**。实现时先做「公共机制 + 公共卡池」地基，再逐角色铺卡，
> 每张卡用现有的 `DealDamageEffect`/`AddStatusEffectEffect`/`DrawCardsEffect` 或新增 Effect 落地。

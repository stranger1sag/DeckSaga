# DeckSaga —— 原创机制体系 & 四角色构筑设计（深度版）

> 目标：**机制要丰富、偏原创**（不照抄杀戮尖塔），有**决策深度**，
> 且先**不考虑可实施性**（代码可以自写）。
> 每个角色有 **2~3 个专属机制 + 卡池 ≥ 30**，卡牌**不强绑流派、留通用性**。

---

# 第一部分 · 核心机制体系（原创 + 有决策深度）

> 这些机制不是「力量/虚弱/中毒」那些直接数值，而是**结构性玩法**，
> 逼玩家在「信息 / 节奏 / 资源 / 站位 / 风险」之间做取舍。

### ◆ A. 架势系统（Stance）—— 属性取向 + 切换代价
- 玩家持有一种「架势」：**雷霆**、**磐石**、**疾影**（不是单纯攻/防）。
- 招式牌会**切换**架势；不同架势下同一种牌有不同的强化。
- **张力的点**：切架势要花一个「行动位」，所以切到哪个架势、何时切，是核心决策。
- 例子：`雷霆架势`下攻击+3；`磐石架势`下格挡牌翻倍；`疾影架势`下抽牌/能量更优。

### ◆ B. 热度系统（Heat）—— 高压体温计
- 打牌会**升热度（0~100）**；热度 ≥60 时攻击伤害上浮，但**回合结束按热度自损**。
- 「散热」卡降温；「燃爆」卡在热度≥90 时打出超强爆发。
- **张力**：升温换爆发，但高温自伤 —— 你愿承担多少风险？

### ◆ C. 印记 · 三色引爆（Sigil）—— 同色叠满引爆
- 对敌人施加**火/冰/虚**三种印记；同种印记最多叠 3。
- 第 3 枚同色印记**引爆**：火=灼烧、冰=**冻结下一回合**、虚=受到伤害+50%。
- **张力**：集中叠同色（快引爆）vs 混色（抢节奏、控场）。

### ◆ D. 阵型 / 换位（Formation）—— 前排背刺
- 敌人分居**前/中/后**三排。攻击分「前排/全体/指定排」。
- **侧面/背面**攻击命中敌享受伤害加成；换位卡把敌人**推/拉**到指定排。
- **张力**：是打前排挡刀，还是换位制造背刺。

### ◆ E. 连击节拍（Rhythm）—— 同回合连招
- 本回合**连续**打出牌（没中断）连击数 +1；连击卡按连击数增伤。
- 回合结束连击清零。
- **张力**：先垫连击再重拳收尾；还是憋单发大牌。

### ◆ F. 命数倒计时（Causality）—— 全局节奏器
- 全局「命数」每回合 -1；归零触发**天罚**（双方大伤）。
- 可用卡「**推迟 / 提前 / 转移**」命数；命数本身是资源。
- **张力**：你控制天罚何时降临、落在谁头上。

### ◆ G. 共鸣（Resonance）—— 元素同调
- 卡有**火/冰/虚**属性；手牌同属性 ≥3 时获得共鸣增益（减费或加伤）。
- 某些卡**消耗共鸣**引爆同调。
- **张力**：攒同调放大 vs 及时用掉。

### ◆ H. 借调（Borrow）—— 透支卡牌，要还
- 「借调」牌打出后进「待还区」：**本轮结束必须用同等魔力「偿还」**（下轮才有魔力），
  否则下轮开始扣血/扣能量。
- **张力**：透支下轮资源换本轮爆发。

### ◆ I. 融合（Fusion）—— 合成更强牌
- 手中两张「源质」牌可**融合**成一张更强牌（一键合成）。
- **张力**：留素材合成，还是现在这张也更值。

### ◆ J. 预言 / 窥牌（Foresight）—— 信息优势
- 可「窥视」抽牌堆顶 2 张；预言牌可重排顺序、或**锁**一张到本回合手牌。
- **张力**：信息能不能变成节奏优势。

### ◆ K. 余波（Echo of Last）—— 复制上一张
- 某些效果记录你**上一张打出牌**；「余波」牌**复制上一张牌的效果一次**。
- **张力**：精心安排出牌顺序让余波最大化。

### ◆ L. 潮汐（Tide）—— 回合节律
- 全局**涨潮/退潮**交替：涨潮回合伤害+，退潮回合抽牌/能量+。
- **张力**：顺应潮汐出牌，还是强行逆潮。

### ◆ 通用数值骨架（仍保留，但作为辅助）
`格挡 / 荆棘 / 吸血 / 多段 / 消耗 / 保留 / 能量 / 抽牌` —— 作为大家都能用的「通用零件」，
真正的特色靠上面 A~L 的结构性机制。

# 第四部分 · 落地原则（先不写代码，仅给方向）

1. **机制优先**：先把 `A~L` 的结构性机制定下来（架势/热度/印记/阵型/连击/命数/共鸣/借调/融合/预言/余波/潮汐）。
2. **数据结构**：`Card` 增加「机制标签 + 元素属性 + 触发条件」的规格化字段，方便每张卡用机制组合。
3. **每角色卡池**：按上面 ≥30，落地时逐张建 `CardData`，数值再平衡。
4. **通用卡共享**：公共池（打击/防御/重击/铁壁/战吼/急救/蓄力…）所有角色通用，保证流派卡不占满。

> 这份是**机制导向的设计蓝图**。你确认想出**哪些机制 + 想先做哪个角色**，我们再往下落到「机制实现 + 卡资产」。
